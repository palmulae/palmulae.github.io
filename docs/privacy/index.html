Privacy

Updated November 24, 2026

This website doesn’t use cookies, analytics or ads, and it doesn’t ask you for any information. Its fonts and images come from this site, so a visit doesn’t reach any other company except the host.

Hosting

The site is hosted on GitHub Pages. GitHub logs and stores visitors’ IP addresses for security purposes, as described in GitHub’s documentation and privacy statement.

Email

If you write to info@palmulae.com, your message and address are used only to reply to you. They aren’t sold or shared. The mailbox is hosted by Microsoft 365.

Apps and businesses

Each app or business started under Palmulae has its own privacy policy where it needs one, linked from its page on this site.
