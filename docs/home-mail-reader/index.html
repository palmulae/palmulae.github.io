Home mail reader

A private tool that reads its owner’s own Gmail, read-only.

Home mail reader is a small tool that its owner runs at home to keep up with the owner’s own email. It reads mail with Google’s read-only Gmail access, so it can’t send, change or delete anything.

It’s for one person’s own use. It isn’t offered to anyone else, and no one else signs in to it.
